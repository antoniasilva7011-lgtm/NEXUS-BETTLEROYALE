# NEXUS Battle Royale — Godot prototype

Este diretório contém um protótipo inicial para Android feito em Godot 4.4.1. O projeto Unreal original foi mantido no repositório.

## Estado atual
- Cena 3D criada por código: chão, obstáculos, personagem, câmera e alvos.
- Controles na tela para mover e atirar.
- Exportação Android configurada para ARM64.
- Ainda não é um Battle Royale completo: não há multiplayer, mapa final, inventário, lobby ou zona segura.

O workflow **Build Godot Android APK** tenta compilar o APK e anexá-lo como artefato do GitHub Actions.
